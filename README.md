# Slayer

A third-person dragon combat game made in Unity. Battle an AI dragon using three
animated attacks, with health bars, stagger feedback, and a cooldown-based ability HUD.

## Unity Version

- **Unity 6000.4.3f1** (Unity 6, URP template project)

## Controls

| Input | Action |
| --- | --- |
| WASD | Move |
| SPACE | Jump |
| 1 / Q / Left Mouse Button | Fire Attack |
| 2 / W | Tail Attack |
| 3 / E | Fly Attack |
| ESC | Pause |

## Asset Sources

| Folder | Source |
| --- | --- |
| `Assets/FourEvilDragonsPBR` | "Four Evil Dragons" PBR dragon model pack (Unity Asset Store) — meshes, textures, materials, animations, and prefabs for the player and enemy dragons |
| `Assets/FlipGameDev/Terrain&GrassPack` | "Terrain & Grass Pack" by Flip Game Dev (Unity Asset Store) — terrain, grass, and ground detail |
| `Assets/DiverseSpace` | "Diverse Space Skybox" — skybox material and textures |
| `Assets/HealthBars` | Pixel-art health bar sprites (`.aseprite` sources included) |
| `Assets/Skills/icons_full` | Ability icon artwork for the skill bar |
| `Assets/Scripts`, `Assets/Scenes`, menus, HUD, combat, AI | Custom game code and setup created for this project |
